# 👗 Style.Loom – Fashion E-Commerce Website

A modern and stylish **fashion e-commerce website** built with **HTML, CSS, and JavaScript**. Style.Loom provides a clean shopping experience where users can explore fashion products, filter products by category, add items to the cart, read customer testimonials, and find answers through the FAQ section.

## 🌐 Live Demo

🔗 **Live Demo:**  https://noor-ul-huda34.github.io/Style.loom-file/

---

## 📌 About The Project

**Style.Loom** is a responsive fashion website designed to showcase modern clothing and accessories with a premium and elegant user interface.

The website includes different fashion categories such as:

* 👔 Menswear
* 👗 Womenswear
* 🧒 Kidswear
* 👜 Accessories

It focuses on creating an attractive shopping experience with product collections, category filters, customer reviews, FAQs, and newsletter subscription.

## 🚀 Shopping Journey

The website provides a simple four-step shopping journey:

1. **Discover Trends** – Explore the latest fashion styles.
2. **Effortless Navigation** – Use filters and categories to find products.
3. **Secure Checkout** – Choose a payment method and complete the purchase.
4. **Unbox Happiness** – Receive your fashion products at your doorstep.

## ⚙️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/style-loom.git
```

### 2. Open the Project

```bash
cd style-loom
```

### 3. Run the Website

You can simply open:

```text
index.html
```

in your browser.

For a better development experience, use **VS Code with the Live Server extension**.
